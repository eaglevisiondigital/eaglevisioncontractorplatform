`FinancialCasework({ sources: OperatingSources, enabled?: boolean = false,
onSelectJob?: (jobId: string) => void })` is a default-OFF staff desk using the actual
existing OperatingSources environment. DEV, literal HTTP loopback and explicit local
confirmation precede caller source/input getters and serializers. It creates no
fixtures, financial events, business objects, store, engine, verifier or writer.

The desk composes `readFinancialEvidenceSources` and its canonical financial export
verifier with the existing saved-forecast exception, Finance Desk, job-cost and
invoice-readiness readers. Each admitted job has one searchable case containing its
canonical cost coverage, recorded costs, net unpaid commitments, saved category
remaining inputs, cost-to-complete and contribution when available, original invoice
requirements and exact canonical invoice/event/ledger evidence. Literal filters use
the allowed job/customer/property text and exact job, issued-version, expense,
cost-review event, payment-event and posting IDs. Counts describe admitted jobs,
not complete company history. Review order reuses the existing exception categories;
it does not invent urgency, overdue debt, verified profit or execution priority.

Missing cost/labor coverage withholds aggregate amounts. Explicit saved category
inputs remain visible as inputs, without substituting them for missing actuals.
Missing events never become zero capture/refund or a known balance. Browser fixture
sources genuinely contain no canonical invoice/payment/ledger records. Positive
event fixtures exist only in explicit tests through existing ReleasePreview commands.

No invoice-job foreign key is invented. Cycle12 alone proves the actual invoice →
contract → original offer → exact issued version → immutable job baseline chain,
including organization/customer/property/currency and source scope. Unlinked evidence
remains UNLINKED/UNKNOWN; same-property jobs remain separate. The original readiness
workflow can still be NO_GO and lack a selected invoice while the canonical evidence
pane contains a linked synthetic invoice. This desk does not silently promote its
requirements or imply genuine provider, refund, void or bank-settlement acceptance.

Source inspection focuses **Exact financial casework source** before a separate
**Open exact source job** action. The original job editor remains separate. The
explicit **Open original financial review workflow** action composes the unchanged
Cycle12 `FinancialEvidenceReview` component, which retains its own source inspection,
manual proposals and confirmations. This package adds no proposal/preparation layer.
All C12/C11 correction APIs and canonical repository/job/exception holds remain
authoritative. A new desk, source read, explanation, container or direct C11 call
cannot replay a held exception. No forecast or financial state auto saves.

The staff-selected retained review binds the original root, repositories/models,
source selection, live source input, current eligible staff and exact saved evidence
across the final await and synchronous render/navigation checks. Model/root replacement
resets the component without requiring a parent key. Source/access drift permanently
withholds the old review's amounts and navigation. **Check retained source review**
only checks the exact retained object. **Read current saved sources** is an explicit
new read; its comparison flags changed saved source identities, facts, original
invoice requirements or canonical evidence. It cannot restore the prior UNKNOWN
review, replace a correction packet, reset a hold or reconcile an uncertain business
command. Exact existing C12 packet reconciliation is still read-only. Session memory
and immutable hashes are not durable custody or genuine authentication.
