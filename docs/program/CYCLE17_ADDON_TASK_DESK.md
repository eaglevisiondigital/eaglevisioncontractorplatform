## Browser contract and retained state

Stable region/title: **Add-on task desk**. Initial mode: `offline`; initial human
edition: `property_services`. A current `selectedJobId` hint preselects only its exact
admitted job; absent hints use the original first admitted handle.

1. **Search task desk jobs** literally filters actual admitted source labels/IDs.
   **Task desk job**, **Task desk mode** and **Task desk edition** are chosen once.
   **Open retained add-on review** opens the original controls directly. It does not
   run **Review pinned source** or any later original confirmation.
2. **Add-on task breadcrumbs** shows exact source-bound links. **Exact sources**
   exposes current company/customer/property/job/issued version/saved lock/report/
   published version/hash and the original recorded references.
3. **Inspect task source [kind] [id]** reads that exact original reference. **Return
   to exact task sources** retains its identity; **Return to original add-on review**
   shows the same mounted control with its original inputs/checks/results intact.
4. Job/Mode/Edition breadcrumbs return to the retained immutable context. Selectors
   are disabled after entry, and **Return to original add-on review** never rebinds
   the source, renews its deadline or creates a replacement attempt.
5. **Open same add-on job [label]** is separate optional host navigation only after
   exact source inspection. Host navigation may unmount this presentation; no
   cross-tab/reload/process-loss return or durable-custody claim is made.

`navigateAddonTaskDeskJob(task, record, expected, {current, generation})` re-inspects
through the original reader and validates the original exact job selector before the
callback. Live callback identity and generation are checked before/after that final
source await; removal, replacement or restoration never revives an obsolete callback.
Callback prop changes do not key/remount the desk or original controls. One in-flight
navigation per retained task prevents duplicate concurrent dispatch.

Withdrawal observed before callback dispatch is a known cancellation and preserves
original controls. An ambiguous source-read result or a callback throwing/rejecting
after dispatch leaves the originating task UNKNOWN. A private navigation outcome
marker uses the actual original Operations identity plus tenant/job, so fresh source
wrappers, new mode/edition selection or a new retained task cannot retry the same job.
Callbacks are awaited, including asynchronous rejection. Immutable task/source/record/
packet bodies stay unchanged. Outcome metadata is not a new business reservation,
expiry, lifecycle or engine. Original UNKNOWN, prepared, expired, cancelled and revoked
holds stay authoritative across breadcrumb returns and fresh original-control reads.
