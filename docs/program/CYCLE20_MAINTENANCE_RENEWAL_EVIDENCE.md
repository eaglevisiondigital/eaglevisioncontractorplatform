# Cycle20 · full maintenance and renewal-planning evidence files

The new five-file package composes the existing C19 `MaintenanceSavedRevisions`
workspace with Main's `SavedEvidenceControls`. It does not create a maintenance,
consent, enrollment, renewal, visit, agreement, scheduler or messaging store. The
same job selection, five-tab host, original source handles and command holds remain
owned by their existing modules.

`readMaintenanceRenewalEvidence` returns the **original** C19 saved-source snapshot
and additionally calls the original `readMaintenanceRenewalPlanning`. A WeakMap
retains only the additional canonical read projection and exact reference checks
for that snapshot; it is not a second business record. Other jobs' same-property
plans and opportunities are excluded by exact plan/job identity. No fuzzy dates,
labels or nearest-report matching occurs.

`maintenanceRenewalEvidenceRecipe` persists complete allowlisted saved evidence:
plan cadence/anchors/revisions, exact follow-up report/version/finding references,
manual priority/review/follow-up/scheduled-visit references, canonical occurrence
identities and current recorded contact-v1 evidence. The separate renewal section
contains the actual original planner's same-job candidate selection, staff planning
status, exact recorded visits, channel reference and every blocked/unknown renewal
requirement. Preparation remains staff planning, never enrollment or an agreement.

The context-aware strict parser checks every allowed field, unique bounded dense
arrays, exact date/instant/timezone values and enums, company/customer/property
ownership, plan/source revisions, original occurrence keys and the unchanged
canonical `occurrence()` calculation. Staff-follow-up candidates require their exact
published finding and saved follow-up revision. Renewal rows must correspond one to
one to available same-job occurrences with matching channel/planning references.
UNKNOWN purpose consent, suppression, enrollment, sender and renewal terms cannot
be promoted by changing a file or recomputing its self-hash. Recipient/provider and
all scheduling, sending, renewal and billing authorities remain null/blocked/false.

`assertMaintenanceRenewalEvidenceSource` freshly validates archived plans and
published follow-up sources against actual current same-job C19 readers. Missing
current IDs, future revisions and contradictory same-revision content reject.
Archived contact references must still be actual contact-history rows with the
same recorded channel state. Recorded renewal visit IDs/plan/date/revision and
same-version state must still match actual property rows. Earlier mutable cadence,
review and planning contents are **unverified historical claims**, not signed proof
or current permission. Later contact withdrawal or plan edits cannot revive an
original command, renew a service or authorize a message.

The shared runtime prepares exact complete JSON bytes, verifies integrity,
freshly authorizes opening and requires explicit read-only current/stale
reconciliation before exposing stale content. Download requested means
`FILE_PREPARED_NOT_CONFIRMED_SAVED`; author tests additionally write/reopen real
bytes in disposable local files. Main provides actual browser download/page-loss/
reopen, server-adapter and independent combined evidence. Files restore no canonical
records, generate no business IDs, reset no UNKNOWN and confer no execution rights.
A content digest is not a signature, genuine Auth or operational recovery.

Focused tests cover three brands, the actual original renewal reader, full on-disk
bytes and current/stale reopening, actual saved cadence/follow-up/contact changes,
same-property sibling-job exclusion, wrong tenant/property, unavailable canonical
sources, malformed/forged/privacy/execution fields, revoked staff, original source
and contact changes during final hashing, strict OFF/getter behavior and no writes,
messages or network calls. Main owns responsive/axe/browser evidence and the common
file adapter. Scoped styles preserve the existing contractor palette, original C19
controls, mobile wrapping, readable source IDs and 44px interaction targets.
