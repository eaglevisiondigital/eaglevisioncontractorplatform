Parent: `c3bbfebd8467263f851d7b27ab68eb20c5db4df7`. This additive default-OFF
staff component reads Main's exact `OperatingSources` handles over one actual
Operations/Phase3/Property repository set. It creates no company, customer, job,
estimate, financial store or provider connection.

`readPortfolioFinance` accepts an exact proposal for every selected job, canonical
ISO review time, positive input revision and explicit unpaid-commitment exclusion.
Each proposal replaces only that job's remaining forecast in the existing detached
Finance Desk scenario. Recorded expenses, internal payment/credit adjustments, net
unpaid commitments, immutable issued totals, canonical margin warnings, invoice
requirements and accounting/procurement compatibility remain owned by the existing
engines. Proposed inputs are never saved, posted, approved or sent.

Only already-canonical integer cost components are added. All cost aggregates are
withheld if any selected job's labor/cost coverage is UNKNOWN. Mixed currencies,
duplicate job/expense/review IDs and source substitutions fail closed. Multiple jobs
at one property remain distinct. Issued quoted customer totals are separately
labeled; they are not earned revenue, invoices or debt. Per-job margin ratios retain
their existing canonical calculation; no competing portfolio ratio is invented.

The interface has editable per-job category proposals, two explicit confirmations,
source/coverage cards, readable invoice requirements and exact job navigation.
`openPortfolioFinanceJob` is navigation only and rechecks the complete original live
source set. Main alone mounts it inside the existing default-OFF local preview and
owns desktop/tablet/mobile browser screenshots. Scoped styles use approved contractor
colors, 44px controls and stacked mobile cards; approved layouts/artwork stay intact.

Snapshots are immutable, SHA-bound and retained only in this session. The reader
rechecks original inputs, root/entry/repository/release references, target/selectors,
actual source revisions, current eligible owner/admin and gates after every await,
including the final child verification. Replaced contexts immediately withhold old
UI evidence. Exact read-only inspection returns CURRENT_LOCAL_SOURCE or UNKNOWN;
UNKNOWN never supplies replacement evidence or executes a retry.

Missing actual invoices/contracts remain UNKNOWN/NO_GO. QuickBooks IDs, schema,
accounts, tax mapping and accountant approval remain UNVERIFIED. Category forecasts
are not catalog quantities, supplier quotes or purchase orders. The panel never
calls an invoice, ledger, export/import, expense, payroll, payment, provider or
communication writer. Cost evidence remains staff-only and does not enter customer
projections. No bank settlement, genuine authorization or profit guarantee is made.
