## Existing jobs, modes and exact sources

actual OperatingSelection and C12 `readExternalProposalSource` readers. Its four
available job rows retain exact company/customer/property/job/estimate/issued-version,
saved-lock revision, canonical source hash, published report/version and actual
plan/visit revisions. Same-property jobs retain distinct issued and report sources.
Counts describe prepared admitted source handles, never complete company history.

The original seven canonical kinds stay unchanged: `offline`, `voice`, `receptionist`,
`storm_network`, `accounting`, `procurement` and `trade`. The existing canonical mode
combines Storm and Contractor Network; this package does not invent another engine.
Recorded company industry remains separate from the explicitly human-selected trade
review context. Selecting an edition never maps or changes company identity,
branding, licensing, code compliance or approved scope.

Literal search combines the exact job filter with verified source labels, IDs,
issued/report/workflow references, current included scope/material lines, recorded
time IDs and mode-specific missing requirements. Missing catalog links are retained
as missing, without supplier/price/name matching. Empty results preserve available
coverage. A foreign job or off-filter source is denied without substitution.
Reading requirements does not start a proposal, delegation or original engine attempt.
The internal constant note is explicitly read-only context; the existing scheduled
visit date supplies reader context only, never an incident or timed-availability fact.

## Working inspection and original controls

`inspectAddonReviewSource(view, row.reference)` opens one exact visible retained
source. Named-field projections expose only issued scope descriptions/quantities,
actual included material-line and catalog references, job-specific time IDs/kinds/
timestamps/submission facts, report/version and recorded workflow references. They
exclude costs, rates, payroll, worker/staff identities, contact data and private notes.
The result is staff review evidence, never a customer projection or a second record
store. No time rows are manufactured when existing sources contain none.

`inspectAddonReviewReference(detail, detail.references[n])` independently checks the
exact company/customer/property/job/issued/source identity plus record kind, ID and
version/revision. Available references include the issued version, published report,
plan, scheduled/published visits and actual time/material records. Field insertion
order does not change canonical identity; wrong/missing/foreign identities cannot
borrow another report, time entry, line or sibling job. Source and record headings
receive focus, and Back to advanced selection retains the original filters/context.

`selectAddonReviewJob(detail)` provides a separate current exact existing-job
navigation target after source inspection. `openAddonOriginalControl(detail)`
returns the **same original OperatingSources root** for the unchanged
`ExternalProposalLifecycle` component. The explicit **Open original C12 control**
action mounts that original control beneath the inspected evidence. The user chooses
the original job/mode in its own selectors; no proposal fields, confirmations,
expiry or comparison are copied or automatically submitted.

Every comparison, expiry, cancellation, revocation, delegation and retained hold
still belongs exclusively to the original C12/C11/C10 and canonical engines. This
desk adds no preparation/approval wrapper, synchronization state or attempt IDs.
Source-read attempt labels are observations at the read, not a live claim that no
C12 hold exists. The desk explicitly reports that original lifecycle custody is not
observable from a source read. Fresh desks, source containers, mode/job selections,
labels and IDs cannot reset an original same-repository/job/mode hold. Lost original
comparison or handoff acknowledgments remain UNKNOWN with exact read-only evidence.
