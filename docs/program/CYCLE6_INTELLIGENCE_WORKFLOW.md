## Permanent session attempt and uncertainty

One organization + existing-estimate journey hold is claimed synchronously before
any await. Concurrent calls cannot both begin. PENDING becomes PREPARED only after
all exact source checks; loss, denial, stale source or an ambiguous result leaves
UNKNOWN. Existing, pending or UNKNOWN preparation cannot retry. Changed review input,
actor, job-null selector, version, property or saved lock revision does not bypass the
same-estimate hold. There is no replay, replacement identity, automatic continuation
or cleanup timer. This is an ephemeral execution guard, not a business record/store,
genuine authentication or durable custody. Refresh/process loss is not independent
recovery and cannot establish permission to repeat an uncertain operation.

`readIntelligenceWorkflowAttempt` exposes only authorized read-only status/phase with
`retry:false` and `replacement:null`. It never resumes the attempt.
`inspectIntelligenceWorkflow` verifies only the exact retained review through the
existing inspectors, its content hash and terminal synchronous source fence, returning
CURRENT_LOCAL_SOURCE/STALE/UNKNOWN with no replacement. Copied/rehydrated evidence is
UNKNOWN. Actual source drift can be STALE; withdrawn/revoked access is UNKNOWN rather
than a stale permission. Prior frozen evidence/hash never changes. Successful review
is still preparation only and enables no action.

## One meaningful advanced composition

Advanced review is null unless the human supplies all explicit inputs beforehand:
a bounded synthetic transcript, a known trade edition, selected actual catalog IDs
(which may be empty), and optional procurement selections. The workflow delegates:

1. **Voice-to-Estimate:** the existing literal transcript parser projects exact catalog
   suggestions, quantities, canonical units, literal UTF-16 source spans and warnings.
   Similar wording, missing exact catalog names and unit differences remain warnings;
   there is no fuzzy source match, recognition service, microphone, price or total.
2. **Trade context:** the existing explicit edition projection provides review prompts
   and selected catalog draft fields over the same source. Original contractor industry,
   approved branding and company profile remain unchanged. Licensing, code compliance,
   measurement and physical completion remain UNVERIFIED/NOT_REVIEWED.
3. **Optional procurement:** only exact existing included scope-line/catalog associations
   delegate to the existing procurement review. Missing recorded association produces
   `UNKNOWN_NO_RECORDED_SCOPE_CATALOG_ASSOCIATION` with no review, rather than matching
   descriptions. Valid review retains the same source hash, quantity/unit/catalog/line
   identities and BLOCKED approval. No supplier order, subcontract, expense, price,
   financial truth or technical approval is created.

All delegates consume the same retained source object. Their target/hash/version
identity remains consistent, and any source edit invalidates retained composition.
Suggestions never modify issued scope or invoke the editor/save/issue path. A prepared
core review is not automatically expanded later; inputs are selected before the one
explicit attempt. Unrelated C5 Operations/Storm/Network/accounting/receptionist modules
remain unchanged and separately controlled; this package integrates one useful
advanced path rather than adding placeholder services for them.
