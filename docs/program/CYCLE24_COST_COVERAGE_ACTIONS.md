Inventory found the existing C23 recorded-cost reader already exposes canonical
category totals, exact labor/correction references and invoice/event/ledger details.
The actual gap was action preparation: staff could inspect a source but had no
single validation of its current native state, saved revision, purpose and original
review destination. This package adds that validation, using the original handle.

`validateCostCoverageAction(view, input)` accepts the original
`RecordedCostRequirementsRead`, exact source kind/ID, expected saved job revision and
finite cost-review or invoice-preparation purpose. It retains the original current
source fences and rejects unknown, foreign, stale, executable or extra selections.
Invoice preparation requires an actual original invoice-requirement source.

An actual eligible pending materials commitment points to the existing native
material-review control. A recorded review/event is inspect-only. Labor absent
from canonical locked evidence remains UNPOSTED OR UNVERIFIED, never zero cost.
Actual locked labor is inspect-only and cannot be reopened or posted again. The
result retains the original category amount, canonical projected margin/warnings,
original financial exceptions and independent invoice prerequisites. It performs
no new arithmetic, allocation, posting, invoice issuance, payment or settlement.

`continueCostCoverageAction` requires explicit current confirmation, revalidates the
exact selection immediately and delegates to `continueRecordedCostSource`. The
original same-job continuation owns concurrent attempts and UNKNOWN/no-replay
custody. This module adds no read constructor, handle registry, command hold, source
store or navigation owner. Rereads and changing a presentation label cannot reset
an original uncertain attempt. Navigation never resolves a financial requirement.

`CostCoverageActions` is a small action slot using `SavedRevisionPanelProps`, for
Main to compose alongside the retained C23 panel under the original default-OFF
mode. It does not nest another panel or reproduce the original correction form.
Exact source selection, current revision, explicit review confirmation and original
destination are visible. Source/job/gate replacement remounts the disposable form;
callback generation is checked by original navigation. Scoped contractor colors,
44px controls, visible labels and responsive stacking preserve existing designs.
