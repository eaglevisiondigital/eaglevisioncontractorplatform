# Cycle20 · Recorded priority source navigation

This isolated local package composes unchanged PrioritySavedRevisions with shared
SavedEvidenceControls and a practical exact-source navigation view. Complete allowlisted
priority evidence retains original ranks, facts, explanations, recorded date context,
missing-evidence indicators and exact job/issued/source IDs, versions and hashes. It
never runs a model, reranks cards or infers authority from recommendation text.

The strict portable recipe rejects unknown/private fields, duplicate source keys,
malformed versions and execution markers. Fresh source authorization validates exact
company/customer/property/job/issued ownership and current recorded source references.
A self hash is integrity evidence, not a signature or trusted approval. Historical files
are read-only records; current/stale reconciliation never restores canonical state,
renews original controls or authorizes a navigation/command.

Staff explicitly read current original priorities, inspect an exact visible source,
then choose Open exact existing review. The same original PriorityActions inspection
and continuation guards bind that source to the original DailyWorkContext source
selection and continuation. Only the existing local destination is invoked; Main maps
it to existing retained panels. Before/after source, staff, job, issued, property and
callback-generation checks apply. Async callback acknowledgment is awaited. Competing
same-canonical views share original custody; ambiguous outcomes retain original UNKNOWN
across fresh wrappers. Removing and restoring a callback cannot bypass its generation
fence. File operations never invoke the navigation callback.

Nothing here dispatches, posts finance, creates invoices, sends messages, executes a
contract or changes operational readiness. Prior approved artwork/interfaces, engines,
schema, migration history, frozen recovery artifacts and all release gates remain exact.
Root independently validates browser/mobile/axe, downloaded file reopening and combined
source continuity. No canonical page-refresh/process-crash restoration is claimed.
