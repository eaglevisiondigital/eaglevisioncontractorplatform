then strictly captures the caller's live callback and generation. Own-property
descriptor capture can itself execute Proxy traps. A trap that calls the existing
native owner-revocation operation during the last callback capture previously

- Before invocation, the callback received the original private job after its

immediately before callback invocation and before the local result. Native source,
