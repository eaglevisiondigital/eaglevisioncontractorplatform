# Cycle20 · Recorded cost continuity

This isolated local package composes unchanged CostSavedRevisions and the shared
SavedEvidenceControls. The finance recipe preserves complete allowlisted saved job,
issued-source, canonical cost/margin, expense/review, time, locked-period, invoice
requirement and accounting-reference evidence. It excludes workforce rates, worker
identifiers, supplier prices, private notes and payroll row contents. Strict parsing
rejects unknown fields, duplicate IDs, malformed numbers and authority claims; fresh
current-source checks validate exact immutable issued/source relationships before
historical content is exposed. An integrity hash is not a signature or authorization.

A separate explicit organization-wide ended-period preview invokes only the existing
Phase3Repository.payroll(..., false). It shows every affected canonical job and every
period entry, including rejected or superseded entries excluded by the original engine.
It never represents unposted or missing labor as a known zero cost. Confirmation
invokes only the original internal preparation method with lock=true after rechecking
all organization jobs, workforce/policy/rate state, period bounds and current reviewer.
Deductions are empty; there is no payroll disbursement, invoice, ledger or payment call.

A canonical Operations/organization keyed one-use attempt is reserved before the first
command await, covers overlapping periods and survives fresh view wrappers. Lost or
contradictory acknowledgment and post-invocation access changes retain UNKNOWN. Exact
read-only reconciliation can observe the original period but never clears the hold or
replays a command. Every canonical job revision advances under the original engine;
this is explicitly organization-wide rather than an implied selected-job operation.
Future December demonstration time stays unposted because its period has not ended.

The original costing reader may still report PARTIAL after a corrected entry is locked:
its approved-unposted coverage counts the superseded original while the original payroll
calculator excludes that original. This package characterizes that boundary; it does not
alter either engine or claim complete coverage/invoice readiness.

Evidence bytes can be downloaded and reopened through Main's strict evidence-file
adapter. Download means FILE_PREPARED_NOT_CONFIRMED_SAVED. Reopened historical files
never restore canonical jobs/workforce, renew held controls or authenticate a person.
No refresh/process-crash canonical durability is claimed. Root independently tests
browser file persistence, responsive layout, accessibility and the combined candidate.

Exactly five new files are owned by the Finance author; all prior engines, schema,
approved artwork, protected evidence, migrations and release gates remain unchanged.
Release1.0 remains NOT READY / NOT AUTHORIZED.
