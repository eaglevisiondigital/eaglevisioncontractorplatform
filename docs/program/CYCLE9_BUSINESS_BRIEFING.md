# Cycle 9 business operating briefing

Parent: `c3bbfebd8467263f851d7b27ab68eb20c5db4df7`. Five additive owned files
compose actual `OperatingSources` and existing per-job Daily Operations readers.
There is no competing job, customer, inspection, financial, reminder or AI store.

`readBusinessBriefing` accepts an explicit civil-day/timezone context and input
revision. It retains exact job/customer/property/issued/report/version references,
current Finance coverage and invoice requirements, recorded Field activity and
published documentation. Multiple jobs at one property remain separate contexts.
Date context filters recorded Field activity; other available history remains
labeled context, never complete company coverage or proof of physical completion.

Review ordering is deterministic: evidence gaps first, recorded dates, existing
review area, then exact job/source identity. It does not infer severity, urgency,
deadlines or permission to execute work. Filters combine exact job, area, evidence
type and literal allowed-text search with accurate available/matching counts.
The responsive staff panel has explicit confirmation, useful empty/error/loading
states, progressive card display and exact source detail with keyboard focus.
`openBusinessBriefingSource` reuses the existing report/version/issued-safe navigation;
`openBusinessBriefingJob` is an exact checked navigation reference only.

Existing Copilot/Voice/trade status is read through its public metadata reader. The
briefing consumes no preparation claim, starts no generation and does not duplicate
Voice controls or reinterpret literal requests. Missing status/coverage is UNKNOWN.
Canonical financial calculations and source-safe projections remain in their
original engines; this package performs no financial calculation or action.

Original live roots/entries/repository/release references, source selectors, input,
actual CRM/property/job/workforce/assignment/revision and eligible current owner/admin
are rechecked after every await. Synchronous public child checks also fence Copilot
attempt metadata after the last async operation. Source/context replacement
immediately hides old UI evidence without relying on a parent React key. Snapshots
are immutable, SHA-bound session evidence; exact read-only inspection returns
CURRENT_LOCAL_SOURCE or UNKNOWN, never replacement evidence, replay or durability.

Focused tests cover all three companies, multi-job shared-property identity, exact
published version navigation, combined filters/empty results, recorded-day meanings,
deterministic ordering, current role, foreign targets, live input/selector/gate and
Copilot drift, immutable UNKNOWN results, strict primitive/accessor privacy and no
writers. Main owns the default-OFF DEV/loopback mount, combined responsive browser
proof, screenshots and authoritative CI/register evidence.
