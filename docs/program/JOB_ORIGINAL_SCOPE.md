# Jobs original scope reference

This optional development child of #539 adds a closed **Original job scope** section to the existing Jobs financial view. It reads the existing persisted original job baseline and supports a local JSON reference download. It uses the existing repository, company access and enabled-module checks; it introduces no business store, schema, ledger, route, financial command or provider connection.

Every load and download checks current estimates access and the enabled estimates module before and after the job read. It rejects foreign or duplicate job rows, changed original baseline or regressed revision, malformed scope lines and detached company/job contexts. A source change during the final authority wait withholds output. An earlier company request cannot download or clear the current company's view. Errors are generic. The existing forecast UNKNOWN hold and all existing financial callbacks remain unchanged.

The explicit projection contains only organization/job identity, job name, original issued-version identity, observed revision and original line identity, kind, description, quantity and unit. Costs, rates, prices, markup and private notes are excluded. Descriptions and IDs retain original case. The download is an internal read reference, not an issuance/payment receipt, customer approval, contract, verified work completion or settlement evidence. A read snapshot does not establish continuing session authority while idle. Genuine Auth/MFA and hosted acceptance remain outstanding.
