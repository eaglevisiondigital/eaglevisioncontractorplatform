The stable recipe is `publishedServiceEvidenceRecipe`, kind `customer`, title
`Published service`. Its `read` uses the original C19 `readServiceRevisionReview`;
`projectPublishedServiceEvidence` selects named safe fields only.
`parsePublishedServiceEvidence(value, EvidenceIdentity)` admits exact own data and
uses the actual `parsePropertyReportPage` for native UUID tenant pages and
`projectPublishedHistory` for approved synthetic tenant literals; both use the same
original strict published-report validator. No tenant ID mapping is invented. Source,
report reference, version, visit and plan identities are explicit. Getter/coercion/
serializer/private/extra fields, duplicate provenance and missing version siblings
reject. The entire file contains no actor ID, workforce/rates/payroll/cost/supplier/
internal notes or private repair archive.

`validatePublishedServiceEvidence(payload, currentSnapshot)` is the recipe's
synchronous `assertSource`. It proves immutable issued-source hash/scope and every
archived report ID/version/content/hash/visit/plan/job against actual current C19
history. A self-recomputed file hash grants no source authority. An old exact report
may coexist with a newer published sibling; shared reconciliation then classifies
the earlier full-content file `STALE_SAVED_EVIDENCE`. A missing, rewritten, foreign
or rebound report rejects UNKNOWN rather than becoming a substitute report.
