and optional `onSource` navigation callback. `readGrowthWorkflow(repo, target,

The load action reads actual existing published maintenance findings through
`PropertyRepository.maintenance`, with exact report/version/finding, visit, plan,
job and current maintenance review revision. Observations, recommendations, reported
severity and manual priority/review/follow-up remain separate. No text similarity,
missing-later-report inference, repaired/resolved status or new opportunity store is
introduced. Only exact selected-job plan associations enter the view. Hidden findings,
internal notes, supplier/pricing/payroll and private workforce fields are excluded.

`readGrowthReminderReview` and `readMaintenanceRenewalPlanning` supply anchored
recurrence, exact visit coverage, candidate identity, due dates/timezones and captured
contact-v1 channel evidence. The panel shows why a candidate has an existing visit,
is outside the disclosed horizon or lacks eligibility. A draft or after-phase visit
prevents duplicate occurrence planning; it does not prove physical completion.

An explicit **Prepare staff visit proposal** action passes the retained exact
candidate to existing `prepareMaintenanceVisitProposal`. It creates only that
engine's detached immutable planning snapshot and content-derived identity. No visit,
appointment, queue, agreement, recipient, enrollment, billing or provider command is
created. Foreign/cloned candidate objects cannot import the current view's provenance.
Repeated reads are not command retries; no execution attempt exists in this package.

The collapsed optional opportunity review requires a user-selected existing purpose
and an explicitly typed synthetic note. It composes existing `prepareGrowthOpportunity`;
no transcript is fabricated from inspection text. Literal cancellation/opt-out signals
remain review evidence, not instructions. No microphone, telephone, model, customer
response, message, lead creation, external fetch or automatic action occurs.

`openGrowthWorkflowSource(view, source)` accepts a retained finding source and returns
navigation-only context with exact organization/customer/location/job/plan/report/
report-version/finding and maintenance revision. Main owns navigation and the
destination's separate source checks. It does not create a customer link or grant.
